# LeoChrono

Huawei Watch GT 6 (46 mm) watch-face project.

## Design
Black background, blue and emerald waves, red heart, large 24-hour time, Croatian uppercase date, heart rate, weather, steps and battery. No rings or kcal.

## Status
Initial project specification only. **Not yet an installable watch face.** Compatibility with Huawei's supported watch-face tools and package format must be verified. A regular Android APK cannot be used as a GT 6 watch face.

## Croatian dates
Days: NED PON UTO SRI ČET PET SUB.
Months: SIJ VEL OŽU TRA SVI LIP SRP KOL RUJ LIS STU PRO.
